Practice application forms

Each form copies how one applicant system builds its forms, so Job App's form engine can be tried and tested without touching a real application. None of them sends anything anywhere.

  • Greenhouse style: comboboxes that only show their choices while open, a hidden file input.
  • Lever style: questions wrapped in their labels, radio buttons, checkboxes, dropdowns.
  • Ashby style: Yes and No buttons, a field inside a web component, a date.
  • Workday style: several steps, dropdown buttons, a date in two parts, error messages.
  • Company page: a Greenhouse-style form inside a frame on a company's own page.
